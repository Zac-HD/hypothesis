When a failing example involves a function generated by
:func:`~hypothesis.strategies.functions`, we now describe the whole function
once the test has finished, instead of reporting each call as it happens.
Where a pure function returned different values we show a lambda which looks
its arguments up in the mapping of observed calls, such as
``lambda x: {1: 3, 2: 5}[x]``; and where every call returned the same value we
show a constant function such as ``lambda x: 3``.  Inspired by Koen Claessen's
2012 paper `Shrinking and showing functions
<https://dl.acm.org/doi/10.1145/2364506.2364516>`__.
